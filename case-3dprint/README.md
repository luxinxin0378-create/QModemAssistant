# QModem 助手 — 全封闭 3D 打印外壳（微雪 ESP32-S3-LCD-1.47）

给微雪 **ESP32-S3-LCD-1.47 / 1.47B 开发板**（1.47 寸竖条屏，172×320）配的**成品盒式外壳**：全封闭四壁、正面屏幕窗 + 实体按键孔 + 散热槽 + RGB 导光孔、底面斜条散热格栅。配合 `esp32-firmware/` 固件，摆在路由器旁显示信号。

## 适配的板子

尺寸来自官方产品尺寸图（你发的截图）：

| 项目 | 数值 |
|------|------|
| PCB 外形 | 36.37 × 20.32 mm |
| 屏幕 | 1.47" 172×320，显示区约 17.7 × 32.9 mm |
| 安装孔 | 4 × M2，孔距 32.43（长向）/ 17.78（短向） |
| USB | Type-C，在短边一端 |
| 按键 | BOOT / RST 贴片按键，在 Type-C 端、分列两侧 |

> 如果你买的是 **1.54 寸**（240×240 正方屏）那块板，外形不同，不能直接用这个壳——把那块板尺寸图发我，我另出一套。

## 文件

| 文件 | 说明 |
|------|------|
| `case_base.stl` | 底壳：封闭四壁 + 底板，内腔卡 PCB，底部支柱给背面元件让位，**底面斜条散热格栅**，Type-C / TF 卡侧开口，四角 M2 螺丝柱 |
| `case_lid.stl` | 上盖：圆角屏幕窗 18×30，正面 **BOOT/RST 按键孔 ×2**，RGB 导光孔，屏幕窗上方短散热槽，四角螺丝通孔 |
| `case_button.stl` | 按键帽 ×2：带法兰小圆柱，粘在板子贴片按键上，穿过上盖孔伸出——实现"壳体按键"手感 |
| `case_preview.png` | 三视图预览（上盖正面 / 底壳内部 / 底壳底面） |
| `generate_case.py` | 参数化生成脚本，改顶部参数即可适配其它板子 |

## 打印参数建议

- **材料**：PLA 即可（想耐温用 PETG）
- **层高**：0.15–0.2 mm；**填充**：20%；**壁厚**：≥ 1.2 mm（脚本按 2.2 mm 设计）
- **支撑**：不需要（开窗、孔、格栅都是贯穿结构）
- **方向**：底壳开口朝上平放打印，上盖正面朝上平放打印
- 三个 STL 均为**闭合网格**，已验证可直接切片

## 装配

1. PCB **屏幕正面朝上**放入底壳内腔（内腔 21.6 × 37.7 mm，单边留 0.65 mm）
2. 板子四角 M2 孔对准底壳里的 4 根支柱
3. **按键帽**：两个 `case_button.stl` 打印件，法兰端涂少量502/双面胶粘在板子的 BOOT、RST 贴片按键上
4. 盖上上盖，让两个按键帽从正面按键孔伸出；四角用 **M2 × 6 螺丝**拧入底壳（底壳为自攻底孔 Φ2.0，也可配 M2 铜螺母更耐用）
5. 检查：屏幕从窗口露出、按键帽能按动、Type-C 能插线、TF 卡能进出、RGB 灯从导光孔透光

## 尺寸汇总

- 外壳外形：**26.02 × 42.07 × 8.70 mm**（底壳 6.5 + 上盖 2.2）
- 底壳内腔：21.62 × 37.67 mm；单边间隙 0.65 mm
- 屏幕窗：18 × 30 mm 圆角（R1.6），中心偏 Y+ 端 2 mm
- 按键孔：2 × Φ4.5，中心 X=±7、Y=-16 mm
- 散热：底面 7 条斜槽（宽 1.6 / 间距 2.9），上盖 5 条短槽
- 螺丝孔：底壳 Φ2.0 自攻 / 上盖 Φ2.3 通孔

## 修改尺寸 / 按键位置

编辑 `generate_case.py` 顶部参数区：

```python
BOARD_W, BOARD_H = 20.32, 36.37   # PCB 外形
CLEAR = 0.65                       # 单边装配间隙
WALL = 2.20                        # 壁厚
BTN_X, BTN_Y = 7.00, -16.00        # 按键孔位置(按实物微调)
WIN_W, WIN_H = 18.00, 30.00        # 屏幕窗
```

运行 `python3 generate_case.py` 重新生成（依赖 `trimesh` + `manifold3d` + `matplotlib`）。
