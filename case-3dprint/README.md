# QModem 助手 — 3D 打印外壳（微雪 ESP32-S3-LCD-1.47）

给微雪 **ESP32-S3-LCD-1.47 / 1.47B 开发板**（1.47 寸竖条屏，172×320）配的桌面小外壳，配合 `esp32-firmware/` 固件使用，直接摆路由器旁显示信号。

## 适配的板子

尺寸来自官方产品尺寸图（你发的截图）：

| 项目 | 数值 |
|------|------|
| PCB 外形 | 36.37 × 20.32 mm |
| 屏幕 | 1.47" 172×320，显示区约 17.7 × 32.9 mm |
| 安装孔 | 4 × M2，孔距 32.43（长向）/ 17.78（短向） |
| USB | Type-C，在短边一侧 |

> 如果你买的是 **1.54 寸**（240×240 正方屏）那块板，外形不同，不能直接用这个壳——告诉我，我按那块板的尺寸另出一套。

## 文件

| 文件 | 说明 |
|------|------|
| `case_base.stl` | 底壳：内腔卡住 PCB，底部 4 根支柱垫高给背面元件让位，四角 M2 螺丝孔，一侧 Type-C + TF 卡开口，两侧 BOOT/RST 按键孔 |
| `case_lid.stl` | 上盖：屏幕开窗 18.1 × 33.3 mm，四角 M2 通孔 |
| `case_preview.png` | 3D 预览图 |
| `generate_case.py` | 参数化生成脚本，改顶部参数即可适配其它板子 |

## 打印参数建议

- **材料**：PLA 即可（想耐温用 PETG）
- **层高**：0.2 mm；**填充**：20%；**壁厚/外壳**：≥ 1.2 mm（脚本里已按 2.4 mm 墙设计）
- **支撑**：不需要（开窗和孔都是贯穿结构）
- **方向**：底壳开口朝上平放打印，上盖正面朝上平放打印
- 两个 STL 均为**闭合网格**，已验证可直接切片

## 装配

1. PCB **屏幕正面朝上**放入底壳内腔（内腔 21.5 × 37.6 mm，单边留 0.6 mm 间隙）
2. 板子四角 M2 孔对准底壳里的 4 根支柱孔位
3. 盖上上盖，四角用 **M2 × 6 螺丝**拧入底壳（底壳孔为自攻底孔 Φ2.1，可直接攻入；也可配 M2 铜螺母更耐用）
4. 检查：Type-C 能插线、TF 卡能进出、侧面按键能按到

## 尺寸汇总

- 外壳外形：**26.32 × 42.37 × 9.0 mm**（底壳 7 + 上盖 2）
- 底壳内腔：21.52 × 37.57 mm
- 屏幕开窗：18.1 × 33.3 mm
- 螺丝孔：底壳 Φ2.1 自攻 / 上盖 Φ2.3 通孔，中心距边框 1.8 mm

## 修改尺寸

编辑 `generate_case.py` 顶部参数区，例如：

```python
BOARD_W, BOARD_H = 20.32, 36.37   # PCB 外形
SCREEN_W, SCREEN_H = 17.70, 32.90 # 屏幕显示区
CLEAR = 0.60                       # 单边装配间隙
WALL = 2.40                        # 壁厚
```

然后运行 `python3 generate_case.py` 重新生成三个文件（需要 `trimesh` + `manifold3d`）。
