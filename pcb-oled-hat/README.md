# QModem OLED HAT — ESP32-S3 SuperMini 专用扩展板

插在 **ESP32-S3 SuperMini** 上的 0.96 寸 IIC OLED 扩展板。**屏幕平放**（直排针焊在板顶，屏体朝板外伸出、显示面朝上），扩展板正面板载一颗 **K1 配网键**（单击进 WiFi 配网）。**复位靠断电**（拔电再上电），不设 RESET 按键。不用翻面、不用飞线。

> ⚠️ 适配板型：板面丝印 **`ESP32-S3 Super Mini`**、外形 **22.52 × 18 mm**、双排各 **9 孔**（排距 15.24 mm / 孔距 2.54 mm）。**不是** ESP32-C3 SuperMini（那是 8 孔一排），下单前务必核对你的板子。

## 布局与按键

- **屏幕平放**：OLED 模块用直排针焊在扩展板板顶（Y-端）的 4 个焊盘，屏体朝板外平躺伸出，显示面朝上。屏幕伸到板子外侧，因此**不遮挡扩展板正面的配网键**。
- **配网键 K1**：扩展板正面焊一颗 **6×6 mm 轻触开关**，接 **IO4（信号）+ GND**（底板 BOOT/GPIO0、RESET/EN 都没引到排针，用不了，所以用引出的 IO4）。**单击一下**进 WiFi 配网。
- **复位**：不设按键，**直接断电再上电**即可（等同硬件复位）。

> 关于 IO4：这是排针上已引出的空闲 GPIO，固件 `s3mini_oled_096` 环境已把配网键配到 IO4（`CFG_PORTAL_PIN=4`）。换别的脚要同时改 PCB 走线和固件里的这个值。

## 引脚连接

| OLED | 扩展板焊盘 | 接到 S3 |
|------|-----------|---------|
| GND  | GND | GND |
| VCC  | 3V3 | 3V3 |
| SCL  | SCL | **IO9** |
| SDA  | SDA | **IO8** |

| 配网键 K1 | 接到 S3 |
|-----------|---------|
| 一侧 | **IO4** |
| 另一侧 | GND |

与固件 `s3mini_oled_096` 环境默认引脚一致；如需换脚，改 `platformio.ini` 里的 `OLED_SDA` / `OLED_SCL` / `CFG_PORTAL_PIN`。

## 打样参数（嘉立创等）

| 项目 | 建议值 |
|------|--------|
| 板材 / 厚度 | FR-4 / **1.0 mm** |
| 铜厚 | 1 oz |
| 板子外形 | 22.52 × 26 mm |
| 孔 | 全部 1.0 mm，共 **26 个**（排针 18 + OLED 4 + 配网键 4） |
| 阻焊 / 字符 | 绿油白字（任意） |
| 数量 | 5 片起 |

上传 `generated/` 目录下 **全部 6 个文件**（5 个 `.gbr` + 1 个 `.drl`）即可。Gerber 为 RS-274X、单位 mm、含 `M02*` 标准结束符，钻孔为 Excellon 公制。

## 焊接步骤

1. 把 **2×9 排针母座**焊在扩展板两排孔（插到底板用），焊盘在底层（B.Cu）。
2. 把 **直排针**焊在板顶 4 个 OLED 焊盘（GND/3V3/SCL/SDA），针脚朝上。
3. 把 0.96 OLED 模块插到排针上，**平躺、屏体朝板外伸出、显示面朝上**（接线按上表，若屏不亮先核对 GND/VCC）。
4. 把一颗 **6×6 mm 轻触开关**焊在正面 K1 的 4 个焊盘（同侧两脚是一组：下侧两脚 GND、上侧两脚 IO4；若接反调换即可，按键不分极性）。
5. 扩展板对准底板两排排针插下，插到底。

> 若 OLED 或按键焊盘位置有偏差（板子批次差异），改 `generate_pcb.py` 里的 `oled` / `K1` / `IO4_PIN` 坐标重跑即可。

## 配套固件

仓库 `esp32-firmware/` 目录，`s3mini_oled_096` 环境（配网键已设为 IO4），支持手机配网（无需改代码填 WiFi）。烧录：`pio run -e s3mini_oled_096 -t upload`。
