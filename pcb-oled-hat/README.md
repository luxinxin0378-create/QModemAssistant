# QModem OLED HAT — ESP32-S3 SuperMini 专用扩展板

一块插在 **ESP32-S3 SuperMini** 上的 0.96 寸 IIC OLED 扩展板。**屏幕立式安装**（竖在板边、显示面朝前），板顶只引出一个**配网键**（单击进 WiFi 配网）——两者互不遮挡，不用翻面、不用飞线。**复位靠断电（拔电重新上电）实现，不设 RESET 按键**。

> ⚠️ 适配板型：板面丝印 **`ESP32-S3 Super Mini`**、外形 **22.52 × 18 mm**、双排各 **9 孔**（排距 15.24 mm / 孔距 2.54 mm）。**不是** ESP32-C3 SuperMini（那是 8 孔一排），下单前务必核对你的板子。

## 为什么屏幕立式

- **平放正面**（朝上）：0.96 OLED 模块约 27×27 mm，会盖住板上的 BOOT 贴片按键
- **平放背面**（朝底板）：显示面贴着底板看不见，设备翻过来则按键朝下按不到
- **立式**（本方案）：90° 弯排针把屏竖在板边，显示面朝前水平可见，配网键从顶面直接按——**唯一能同时"看得见 + 按得到"的装法**

## 按键说明

板上只引出一个**配网键 CFG**（对准底板的 BOOT/GPIO0 贴片按键）：**单击一下**即进入 WiFi 配网热点，用手机配置。复位不需要按键——**直接断电再上电**即可（等同于硬件 RESET）。

## 引脚连接

| OLED | 扩展板焊盘 | 接到 S3 |
|------|-----------|---------|
| GND  | GND | GND |
| VCC  | 3V3 | 3V3 |
| SCL  | SCL | **IO9** |
| SDA  | SDA | **IO8** |

与固件 `s3mini_oled_096` 环境的默认引脚一致；如需换脚，改 `platformio.ini` 里的 `OLED_SDA` / `OLED_SCL`。

## 打样参数（嘉立创等）

| 项目 | 建议值 |
|------|--------|
| 板材 / 厚度 | FR-4 / **1.0 mm** |
| 铜厚 | 1 oz |
| 板子外形 | 22.52 × 26 mm（顶部延伸 8 mm 放 OLED 焊盘） |
| 孔 | 排针孔 1.0 mm、配网键孔 3.4 mm，共 23 个 |
| 阻焊 / 字符 | 绿油白字（任意） |
| 数量 | 5 片起 |

上传 `generated/` 目录下 **全部 6 个文件**（5 个 `.gbr` + 1 个 `.drl`）即可。Gerber 为 RS-274X、单位 mm、含 `M02*` 标准结束符，钻孔为 Excellon 公制。

## 焊接步骤

1. 把 **2×9 排针母座**焊在扩展板两排孔（插到底板用），焊盘在底层（B.Cu）。
2. 把 **90° 弯排针**焊在顶部 4 个 OLED 焊盘，弯折方向朝板外（让屏竖起后显示面朝前）。
3. 把 0.96 OLED 模块插到弯排针上，屏体竖直，显示面朝外。
4. 把 **1 个按键帽**（`button_cap.stl`，可 3D 打印）用双面胶粘在底板 BOOT 贴片按键上，使其穿出扩展板那个 Φ3.4 孔、顶面略高于板面（配网键）。复位不用按键，断电即可。
5. 扩展板对准底板两排排针插下，插到底。

> 若 BOOT 贴片按键位置与孔位有偏差（板子批次差异），改 `generate_pcb.py` 里的 `BTN` 坐标重跑即可。

## 文件说明

| 文件 | 说明 |
|------|------|
| `generate_pcb.py` | 参数化生成脚本（改尺寸/孔位/走线后重跑） |
| `generated/*.gbr` | 5 层 Gerber：F.Cu / B.Cu / F.Mask / F.SilkS / Edge.Cuts |
| `generated/*.drl` | Excellon 钻孔 |
| `preview_top.png` | 顶层布线和孔位预览 |
| `preview_assembly.png` | 装配侧视（屏幕立式 / 单个配网键朝上） |
| `button_cap.stl` | 配网键帽，粘在 BOOT 贴片按键上穿出扩展板孔 |

## 配套固件

仓库 `esp32-firmware/` 目录，`s3mini_oled_096` 环境，支持手机配网（无需改代码填 WiFi）。
